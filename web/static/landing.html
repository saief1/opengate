Features

Everything between your app
and the model.

Use one, or all. Each piece works with any provider.

Request logs

Every request, token and cent — queryable, streamed live.

Budgets & limits

Hard caps per org, key, customer or project, enforced before the provider is called.

Kill switch

Stop a runaway agent or the whole organization. Confirm by typing the project name.

Fallbacks & routing

Model aliases with retries and failover chains. Other providers are translated both ways.

Guardrails

PII redaction, prompt-injection filters and model allow lists.

OpenAI-compatible

Change one base URL. Works with every SDK and framework. Apache-2.0, one Go binary.
